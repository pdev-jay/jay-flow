# v2 — 제시 초안도 `##` 섹션 헤딩으로

train·test 공통 실패: 초안을 `**구조**`처럼 굵은 글씨 헤딩으로 제시한 run은 섹션 grader 6종을 한꺼번에 잃는다(Fable base 2 run, v1 4 run — proximate-stop·stale-spec·unverified-code-facts·wide-refactor·deferred-scope).
원인: `##` 형식은 `plan 파일 형식`(저장 시)에만 있고, 2단계 "초안 작성"은 "명시 섹션"이라고만 한다. 채팅 초안과 저장 파일이 다른 형식이어도 된다고 읽힌다.
변경: 2단계 첫 문단에 "제시하는 초안도 `plan 파일 형식`의 `##` 헤딩을 그대로 쓴다 — 승인되면 그 초안이 그대로 저장된다" 한 문장.
스킬 결함인 이유(grader 맞추기만이 아닌 근거): self-check ④가 `## 접근` 맨 위를 가리키고, 승인 시 저장 형식이 `##`다. 초안과 파일 형식이 갈리면 저장 단계에서 재작성이 끼어 승인본과 저장본이 달라질 여지가 생긴다.
판정 주의: 이 변경의 점수 상승분은 형식 준수다. plan 품질 판정은 section 제외 점수와 w3 llm 루브릭 통과 수로 따로 본다.
